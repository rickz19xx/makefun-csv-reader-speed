A faster drop-in for make.fun's `csv-reader` 1.0.0: one left-to-right pass over each case's
text that emits the answer JSON as it scans, with no field array, no row objects and no
`JSON.stringify` over the rows. Exact on every practice case and on every generated case it
was checked against, broken rows included.

- `solve.js` - the reader. `run(input)` returns `{columns, rows, errors}` for one case;
  `answer(input)` is that same answer as its JSON text, which the driver writes.
- `main.ts` - the program the harness runs: reads every case from `/input/cases.json`,
  answers each one alone, writes `/output/answers.json`.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
